## 4. 对接方需向代理/运营方确认的信息

发给代理自研 APP 前，建议运营侧同时提供：

| 项 | 说明 |
|----|------|
| 配置根地址 `$url` | 可访问的 `https://…`（保证 `/profile.xml` 可下载） |
| 测试账号 / 密码 | 至少一组可连通账号 |
| 是否需要 MFA | 若需要，说明 OTP 获取方式 |
| 是否固定证书 Pin | 正式环境证书策略 |
| 目标平台 | Windows / Android / iOS 等，便于评估工作量 |
| 全局还是分流 | 影响路由实现复杂度 |

## 5. 对外交付建议清单

向代理交付本目录时，建议一并说明：

1. 协议为 AnyConnect 兼容 SSLVPN，用 OpenConnect 系客户端实现  
2. 节点来自 `$url/profile.xml`  
3. 连接三要素：`HostAddress` + 账号 + 密码  
4. 附 `profile.xml.sample`（示例域名）供开发自测解析  
5. 正式 APP 推荐 libopenconnect 库模式，注意 LGPL
