# 01 — 协议概述

## 1. 协议名称

本服务提供的是 **Cisco AnyConnect 兼容 SSL VPN**。

| 常见叫法 | 含义 |
|----------|------|
| SSLVPN | 业务侧统称 |
| Cisco AnyConnect / ASAv SSL VPN | 网关侧协议族 |
| OpenConnect | 开源客户端/库对上述协议的实现名称 |

第三方自研 APP 时，技术选型通常落在：

- **libopenconnect**（推荐，库内嵌）
- **openconnect** 命令行（仅联调/原型，不建议正式产品）
- 其它 AnyConnect 兼容实现（需自行验证互通）

## 2. 协议能力概要

| 能力 | 说明 |
|------|------|
| 传输 | 先 HTTPS 认证，再建立 CSTP（TLS/TCP）数据通道 |
| 加速 | 可协商 DTLS（UDP）；失败则回退 CSTP，不影响连通 |
| 虚拟网卡 | 客户端创建 TUN/TAP，收发内网/代理流量 |
| 认证 | 用户名 + 密码；部分网关可能要求 MFA/OTP（按需扩展） |
| 配置下发 | 连接成功后网关下发 IP、DNS、路由/分流信息 |

## 3. 对接方式

自研 APP **只需**能：

1. HTTP(S) 下载并解析 `profile.xml`
2. 用三要素（网关 URL + 账号 + 密码）连接 SSLVPN 网关

## 4. 兼容性说明

- 网关为 AnyConnect 兼容族（含常见 Cisco ASAv / 兼容设备）。
- 客户端实现需声明协议名为 `anyconnect`（libopenconnect：`openconnect_set_protocol("anyconnect")`）。
- 不同网关在证书校验、认证表单字段（group / MFA）上可能有差异；基础「账号+密码」为必支持项。

## 5. 不在本资料范围

- WireGuard、IPSec、其它非 SSLVPN 协议
- 服务端（ocserv / ASAv）部署与运维
