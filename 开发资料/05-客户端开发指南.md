# 05 — 客户端开发指南

## 1. 推荐实现路径

| 方案 | 说明 | 适用 |
|------|------|------|
| **A. 库模式（推荐）** | 进程内链接 / 调用 libopenconnect | 正式 APP |
| B. 命令行包装 | 拉起 `openconnect` 进程 | 仅原型/内部工具 |
| C. 自研协议栈 | 从零实现 AnyConnect | **不推荐**（成本与兼容性风险高） |

正式产品请优先 **方案 A**：稳定性、可控性更好，也避免依赖用户机器上另装 CLI。

## 2. 技术选型参考

### 开源核心

| 组件 | 用途 |
|------|------|
| [OpenConnect](https://gitlab.com/openconnect/openconnect) | libopenconnect 源码与 C API |
| [OpenConnect GUI](https://gitlab.com/openconnect/openconnect-gui) | 桌面 GUI 参考（含 Windows 打包依赖思路） |
| [协议说明](https://gitlab.com/openconnect/protocol) | AnyConnect 兼容协议资料 |
| [Wintun](https://www.wintun.net/) | Windows TUN 驱动（常见依赖） |

### 各平台提示

| 平台 | 提示 |
|------|------|
| **Windows** | 使用 MinGW/MSVC 构建的 `libopenconnect-*.dll` + 依赖（GnuTLS、libxml2、zlib 等）；TUN 用 Wintun 或 TAP；连接常需管理员权限 |
| **Android** | 可基于 openconnect 安卓移植或自建 JNI；必须走系统 `VpnService`；注意前后台与电池策略 |
| **iOS** | 需 Network Extension；评估上架政策与第三方库许可；实现成本高于 Android |
| **macOS / Linux** | libopenconnect 或官方 CLI；权限与路由由系统 API / vpnc-script 处理 |

## 3. libopenconnect 关键 API（概念映射）

| 步骤 | C API（示意） |
|------|----------------|
| 创建会话 | `openconnect_vpninfo_new` |
| 设协议 | `openconnect_set_protocol(..., "anyconnect")` |
| 解析 URL | `openconnect_parse_url` |
| 认证 | `openconnect_obtain_cookie`（配合 auth form 回调） |
| CSTP | `openconnect_make_cstp_connection` |
| DTLS | `openconnect_setup_dtls` |
| TUN | `openconnect_setup_tun_device` / 平台 fd 方案 |
| 运行 | `openconnect_mainloop` |
| 释放 | `openconnect_vpninfo_free` |

完整签名以官方头文件 `openconnect.h` 为准。

## 4. APP 功能最小集

实现以下即可完成对接验收：

1. 配置 `$url`、账号、密码并本地保存  
2. 下载并解析 `$url/profile.xml`  
3. 展示节点列表（`HostName`）  
4. 选中节点后用 `HostAddress` + 账号 + 密码连接  
5. 显示连接中 / 已连接 / 失败原因  
6. 断开连接并恢复网络状态  
7. （建议）退出登录清除本地凭证  

## 5. UI 建议

```
页面 A — 登录配置
  [服务器地址 $url]
  [账号]
  [密码] [记住密码]
  [登录 / 获取节点]

页面 B — 节点与连接
  节点列表（可下拉刷新）
  [连接] [断开]
  状态与简要日志
```

- 本地已有账号+密码 → 启动直达页面 B，并自动刷新 profile  
- 无凭证 → 页面 A  

## 6. 安全与权限清单

| 项 | 要求 |
|----|------|
| 密码存储 | 系统安全存储，禁止明文写日志 |
| 传输 | profile 与 VPN 均走 HTTPS/TLS |
| 证书 | 正式包默认校验；联调开关与正式开关分离 |
| 权限 | Windows 管理员 / Android VPN 授权 / iOS NE 权限提前说明 |
| 依赖许可 | libopenconnect 多为 **LGPL**：动态链接并附 NOTICE / 源码获取说明 |

## 7. 联调检查清单

- [ ] `GET $url/profile.xml` 返回 200 且能解析出 ≥1 个 `HostEntry`
- [ ] `HostAddress` 含端口与路径时连接仍成功
- [ ] 错误账号有明确失败提示
- [ ] 连接成功后虚拟网卡存在，业务访问符合预期
- [ ] 断开后路由/DNS 恢复正常，可再次连接
- [ ] 冷启动（已保存凭证）自动刷新节点列表
- [ ] 任务管理器 / 进程列表中**无**非预期的 `openconnect.exe` 子进程（若宣称库模式）

## 8. 常见问题

| 现象 | 可能原因 |
|------|----------|
| profile 404 | `$url` 写错或未部署 `profile.xml` |
| 解析 0 个节点 | 命名空间未处理 / 非 ServerList 结构 |
| 认证失败 | 账号密码错误、缺 group、需 MFA |
| TUN 失败 | 无管理员权限、缺少 Wintun/TAP、驱动未装 |
| 能连上但不上网 | 路由/DNS 未下发或被系统策略覆盖 |
| DTLS 失败 | 正常，应回退 CSTP |
