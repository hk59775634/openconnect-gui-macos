# 02 — 接入方式与三要素

## 1. 连接三要素（必读）

建立 SSLVPN 会话只需要以下三项：

| 要素 | 来源 | 说明 |
|------|------|------|
| **url** | `profile.xml` 中节点的 `HostAddress` | VPN 网关完整地址（含协议、主机、端口、路径） |
| **账号** | 用户输入 | 建议本地加密保存，连接时使用 |
| **密码** | 用户输入 | 建议本地加密保存，连接时使用 |

> 凭证只在连接时交给 OpenConnect / 协议库。

## 2. 服务器根地址 `$url`

用户或代理配置的是 **配置服务根地址**（不是某个具体节点）：

```text
示例：$url = https://vpn.example.com
```

客户端用它拉取节点列表：

```text
GET {$url}/profile.xml
```

注意区分：

| 概念 | 例子 | 用途 |
|------|------|------|
| 配置根地址 `$url` | `https://vpn.example.com` | 仅用于下载 `profile.xml` |
| 节点网关 `HostAddress` | `https://gw.example.com:10000/hkg` | **真正发起 VPN 连接** |

## 3. 推荐产品流程

```
┌─────────────────┐
│ 登录 / 配置页    │  输入：$url、账号、密码
│                 │  动作：GET $url/profile.xml → 解析节点
└────────┬────────┘
         │ 本地已有完整账号+密码时可跳过此页
         ▼
┌─────────────────┐
│ 节点选择 / 连接  │  展示 HostName 列表
│                 │  选中节点后用 HostAddress + 账号 + 密码连接
└─────────────────┘
```

### 刷新策略建议

| 状态 | 建议行为 |
|------|----------|
| 首次登录 / 未保存凭证 | 登录时拉取一次 `profile.xml` |
| 本地已有账号密码 | APP 每次冷启动进入节点页时再拉取一次，刷新节点 |
| 用户手动刷新 | 提供「刷新节点」按钮，再次请求 `profile.xml` |

## 4. 本地凭证

| 项 | 建议 |
|----|------|
| 账号 | 明文或加密均可；至少持久化 |
| 密码 | **必须加密存储**（Android Keystore / iOS Keychain / Windows DPAPI / 系统凭据库） |
| `$url` | 与账号一并保存，便于下次启动 |
| 退出登录 | 清除本地凭证，回到配置页 |

## 5. 可选扩展字段

基础对接只需三要素。若网关有特殊要求，可再支持：

| 字段 | 说明 |
|------|------|
| `UserGroup` / authgroup | 部分网关认证组；若 `profile.xml` 的 `HostEntry` 带 `UserGroup` 可一并传入 |
| OTP / MFA | 二次验证码；有 MFA 的网关才需要 UI |
| 证书 Pin | 固定服务器证书指纹，提高安全性 |
| 允许不安全证书 | **仅联调**；正式产品勿默认开启 |

## 6. 连接调用示意（伪代码）

```text
nodes = HTTP_GET("$url/profile.xml") |> ParseHostEntries()
selected = nodes[userChoice]          // HostName / HostAddress

ConnectSSLVPN(
  gatewayUrl = selected.HostAddress,  // 例如 https://gw.example.com:10000/hkg
  username   = savedUsername,
  password   = savedPassword
)
```

命令行对照（仅便于理解，正式 APP 建议库模式）：

```bash
openconnect --protocol=anyconnect \
  --user=USERNAME \
  "https://gw.example.com:10000/hkg"
# 随后交互或管道输入密码
```
